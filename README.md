# 📖 About

**Indian National Flag Live Animation** is a responsive HTML5 Canvas web application that renders a waving Indian National Flag with a dynamic Ashoka Chakra animation. The project is built using pure HTML, CSS and JavaScript without external frameworks.

Along with the live animation, users can download the current frame as an HD image, record a short HD video of the animation, and personalize the exported content with a custom credit line.

---

# ✨ Features

- 🇮🇳 Realistic waving Indian National Flag animation
- 🎨 HTML5 Canvas rendering
- ⚡ Smooth animation using `requestAnimationFrame()`
- 🛡 Responsive design for desktop and mobile devices
- 📷 Download HD PNG image
- 🎥 Download HD animated video
- ✍ Customizable credit line for exported media
- 📱 Progressive Web App (PWA) support
- 🔍 Search Engine Optimized (SEO)
- 🌐 Open Graph & Twitter Card support
- 🗺 Sitemap included
- 📌 Google Search Console verification ready
- ⚙ Service Worker support
- 🚀 Lightweight (No frameworks required)

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/shivamkalkiyug/indian-national-flag-live-animation.git
```

Open the project

```bash
cd indian-national-flag-live-animation
```

Run

Simply open

```
index.html
```

in your browser

or use

```bash
python -m http.server
```

then visit

```
http://localhost:8000
```
